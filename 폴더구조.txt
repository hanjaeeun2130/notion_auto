v1 대비 변경점
1. config/triggers.md 신설: 키워드는 사용자가 정하고, 이 표 하나만 고치면 동작이 바뀜
2. 쓰기 경로 추가: notion-writer 에이전트 + trigger-parse / notion-db-write 스킬
3. CLAUDE.md 가 입력을 두 모드로 분기
4. /trigger 명령으로 대화 중에 키워드 관리 가능

입력 분기
[등록 모드] "개인 : 친구와 카페 약속 토요일 3시"
  → 맨 앞 "키워드 :" 가 config/triggers.md 에 있음
  → trigger-parse 로 제목·날짜·시간 등 추출
  → notion-writer 가 개인일정 DB에 등록
  → register-result.md 양식으로 결과 보고 → runs/ 기록

[분석 모드] "오늘 마감 작업 확인해줘" (트리거 키워드 없음)
  → notion-analyst 조회·분석 → report.md 로 보고
  → 사용자 승인 → gws-executor 실행 → runs/ 기록

설계 원칙
1. 키워드 정의(config)와 처리 절차(skills)를 분리 → 키워드를 추가해도 절차 수정 불필요
2. Notion 쓰기 / Notion 읽기 / GWS 실행을 서로 다른 에이전트로 나눠 권한 최소화
3. Notion 삭제는 settings.json 에서 거부, 수정·취소는 보관(archive)으로만 처리
