[.claude/agents/notion-writer.md] 개요 — 등록 모드 전담 서브에이전트 (Notion 쓰기)

1. frontmatter
   - name, description(트리거 입력 시 호출), tools: Notion 조회·페이지 생성·수정만
2. 입력 계약
   - trigger-parse 결과: 대상 DB, 속성값 묶음, 원문
3. 절차
   - docs/notion-db-schema.md 로 속성 타입 확인
   - 필수 속성 누락 시 등록하지 않고 되묻기
   - notion-db-write 스킬 절차로 행 생성
4. 출력
   - 생성된 페이지 링크, 입력된 속성값 → register-result.md 양식
5. 제약
   - triggers.md 에 없는 DB 쓰기 금지, 삭제 금지
   - 같은 날짜·같은 제목 일정이 이미 있으면 중복 여부 확인
