[.claude/skills/trigger-parse/SKILL.md] 개요 — 트리거 입력 해석

1. frontmatter: name, description(트리거 형식 입력 시)
2. 형식 인식
   - "<키워드> : <내용>" / 전각 콜론 / 앞뒤 공백
   - 키워드·별칭을 config/triggers.md 에서 찾기
3. 내용에서 속성 추출 규칙
   - 제목: 날짜·시간 표현을 뺀 나머지
   - 날짜: 오늘, 내일, 토요일, 다음 주 월요일, 11/20 → 실제 날짜 (기준: 현재 날짜·시간대)
   - 시간: 3시, 오후 3시, 15:00 → 시각 (오전/오후 모호할 때의 규칙 명시)
   - 장소·담당자·우선순위 등 DB에 있는 속성만 추출
4. 출력 형식: 대상 DB + 속성값 목록 + 확신 낮은 항목 표시
5. 예시 3~5개 (원문 → 해석 결과)
