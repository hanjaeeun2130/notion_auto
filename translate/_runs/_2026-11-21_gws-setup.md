# GWS CLI 설치 실행 기록 — 2026-11-21

- 요청: npm으로 gws CLI 설치, 인증, 필요한 도구 설치. 브라우저 단계는 사용자 로그인과 동의를 빼고 Playwright가 처리.
- 승인: 사용자가 todo 목록 승인("진행해줘").

| # | 단계 | 결과 |
|---|---|---|
| 1 | `npm install -g @googleworkspace/cli` | gws 0.22.5 설치 |
| 2 | Google Cloud CLI (zip, 무인 설치) | gcloud 594.0.0, `%LOCALAPPDATA%\google-cloud-sdk`에 설치. 설치 프로그램이 PATH를 못 바꿔서 사용자 PATH에 직접 추가 |
| 3 | `gcloud auth login --no-launch-browser` | 로그인 완료 (로그인은 사용자, 인증 코드 전달은 Playwright) |
| 4 | `gws auth setup` | 두 번 실패: 처음엔 프로젝트 없음, 다음엔 "OAuth client creation requires manual setup" |
| 4a | `gcloud projects create notion-auto-gws-34664` | 생성 완료, API 활성화: Calendar, Gmail, Drive, Sheets, Docs |
| 4b | 동의 화면 (Playwright) | 앱 "gws CLI", 외부, 테스트 모드. 데이터 정책 체크와 만들기는 사용자가 진행 |
| 4c | 테스트 사용자 | 추가 완료 (자동 저장이 반영되지 않아 사용자가 저장 클릭) |
| 4d | 데스크톱 OAuth 클라이언트 (Playwright) | 생성 완료, JSON을 `C:\Users\SBS\.config\gws\client_secret.json`으로 이동 |
| 5 | `gws auth login -s calendar,gmail,drive,sheets` | 성공, 암호화된 인증 정보 저장 (동의는 사용자) |
| 6 | `gws auth status`, `drive files list`, `calendar +agenda`, `calendarList list`, `events list` | 모두 종료 코드 0 (읽기 전용) |
| 7 | `docs/gws-cli-reference.md`와 번역본, CLAUDE.md 7절과 번역본, 이 기록 | 작성 완료 |

발견 사항:
- 진흥원 일정은 `primary`가 아니라 별도 캘린더(진흥원(한재은/박유혁/엄태현/서성석))에 있습니다. 제목·설명·장소에 `진흥원`이 들어 있는지로 거르면 대부분 빠집니다.
- 쓰기 명령(Gmail 초안, Docs/Sheets/Drive 생성)은 아직 확인하지 않았습니다.
