# Drive / Docs / Sheets 참고 문서

gws-execute 스킬의 파일 작업 절차와 안전 규칙입니다.

> 명령은 아직 채우지 않았습니다. GWS CLI 설치 후 `gws <command> --help` 로 각 명령을 확인하고, `docs/gws-cli-reference.md` 에 기록한 뒤 아래 표에 옮겨 적습니다.

## 지원 작업

| 작업 | 주요 용도 | 명령 (확인됨) |
|---|---|---|
| Docs 생성 | 분석 보고서 | 미정 |
| Sheets 생성 | 일정·작업 표 | 미정 |
| 내용 입력 | Docs 본문 또는 Sheets 행 채우기 | 미정 |
| 폴더 찾기·생성 | 저장 위치 | 미정 |
| 공유 | 공유 변경 (명시적 승인 시에만) | 미정 |

## 절차

1. **저장 위치 확인.** 작업에 지정된 폴더 사용. 없으면 사용자에게 물어봄. 폴더 ID 조회 (읽기 전용)
2. **파일 이름 확인.** 규칙: `YYYY-MM-DD_<작업명>` (예: `2026-11-14_주간일정`). 폴더에 같은 이름의 파일이 있으면 새 이름을 사용자에게 물어봄. 덮어쓰지 않음
3. 폴더에 파일 **생성**
4. **내용 입력.** Sheets: 머리글 행 + 결과 항목당 한 행. Docs: `templates/report.md` 의 섹션 구성
5. 파일(과 폴더) **링크 반환**

## 안전 규칙

- 덮어쓰기 금지, 삭제 금지
- 기본 공유 범위: 비공개 (소유자만)
- 공유 변경은 반드시 명령 미리보기에 표시되고 명시적으로 승인되어야 함
