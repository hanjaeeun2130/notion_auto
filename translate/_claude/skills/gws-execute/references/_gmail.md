# Gmail 참고 문서

gws-execute 스킬의 메일 작업 절차와 안전 규칙입니다.

> 명령은 아직 채우지 않았습니다. GWS CLI 설치 후 `gws <command> --help` 로 각 명령을 확인하고, `docs/gws-cli-reference.md` 에 기록한 뒤 아래 표에 옮겨 적습니다.

## 지원 작업

| 작업 | 명령 (확인됨) |
|---|---|
| 초안 생성 | 미정 |
| 초안 ID로 전송 | 미정 |
| 초안 수정 | 미정 |
| 초안 목록·조회 | 미정 |

## 절차

1. **수신자 확인.** `docs/notion-db-schema.md` 의 담당자 → 이메일 매핑으로 담당자 이름을 이메일로 변환. 모르는 이름 → 사용자에게 물어봄
2. **템플릿 채우기.** 맞는 템플릿이 `templates/email/` 에 있으면 사용 (예: `deadline-reminder.md`). 없으면 작업 내용으로 제목과 본문 작성
3. **초안 생성** (명령 미리보기 승인 후)
4. 전송 승인을 위해 **초안 보여주기**: 초안 ID, To / Cc, 제목, 본문 미리보기
5. 승인된 초안만 초안 ID로 **전송**. 수신자나 내용은 바꾸지 않음

## 안전 규칙

- **외부 도메인:** 사용자 도메인 밖이거나 담당자 → 이메일 매핑에 없는 수신자는 전송 전에 한 번 더 확인
- **대량 발송:** 메일 1통에 수신자 10명 이상, 또는 한 작업에서 메일 5통 이상이면 전송 전에 한 번 더 승인 (기준값은 여기서 조정)
- 초안 승인 없이 전송 금지. 초안 삭제 금지
