# 규칙: notion-study

**학습 관련 할 일**을 Notion **Study** DB에 저장합니다.

> 우선순위: 이 규칙이 CLAUDE.md, 스킬, 에이전트, `config/`, `docs/` 와 충돌하면 이 규칙을 우선합니다.

## 대상

| 항목 | 값 |
|---|---|
| Notion DB | Study |
| DB ID | (DB 생성 또는 확인 후 채움) |
| 트리거 키워드 | `학습` |
| 별칭 | `공부`, `study`, `배움` |
| 기본값 | 날짜 없으면 오늘 |

## 해당하는 항목

학습 할 일: 강의, 수업, 과제, 시험, 자격증, 독서, 연습, 스터디

예시:
- `학습 : 파이썬 강의 3강 수강 오늘`
- `공부 : 정보처리기사 필기 시험 12/7`

## 규칙

1. 키워드 `학습`(또는 별칭)이 붙은 입력은 **오직** Study 에만 저장
2. 내용이 분명히 다른 분류에 속하면 사용자의 키워드를 유지하되 미리보기에 표시
3. 등록은 notion-db-register 스킬을 따름: 속성 나누기 → 미리보기 → 사용자 승인 → notion-writer
4. Study DB가 아직 없으면 등록하지 않음. 사용자에게 알리고 생성을 제안 (notion-writer 작업 A, 승인 후)
