# 규칙: notion-personal

**개인 할 일**을 Notion **Personal Tasks** DB에 저장합니다.

> 우선순위: 이 규칙이 CLAUDE.md, 스킬, 에이전트, `config/`, `docs/` 와 충돌하면 이 규칙을 우선합니다.

## 대상

| 항목 | 값 |
|---|---|
| Notion DB | Personal Tasks |
| DB ID | (DB 생성 또는 확인 후 채움) |
| 트리거 키워드 | `개인` |
| 별칭 | `사적`, `private` |
| 기본값 | 상태 = 예정, 날짜 없으면 오늘 |

## 해당하는 항목

업무나 학습이 아닌 개인 할 일: 친구·가족과의 약속, 볼일, 집안일, 건강, 취미, 개인 쇼핑, 개인 납부

예시:
- `개인 : 친구와 카페 약속 토요일 3시`
- `개인 : 병원 예약 다음 주 화요일`

## 규칙

1. 키워드 `개인`(또는 별칭)이 붙은 입력은 **오직** Personal Tasks 에만 저장
2. 내용이 분명히 다른 분류에 속하면(예: `개인 : 팀 회의 자료 준비`) 사용자의 키워드를 유지하되 등록 미리보기에 표시: "업무 할 일로 보입니다 — Work 에 저장할까요?"
3. 등록은 notion-db-register 스킬을 따름: 속성 나누기 → 미리보기 → 사용자 승인 → notion-writer
4. 사용자가 미리보기에서 고르지 않는 한 개인 할 일을 Work, Study, 회사에 쓰지 않음
5. Personal Tasks DB가 아직 없으면 등록하지 않음. 사용자에게 알리고 생성을 제안 (notion-writer 작업 A, 승인 후)
